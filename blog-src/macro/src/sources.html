Methods and data

Each FP32/BF16 pair uses the same learning-rate schedule. Different optimizers can use different learning rates. The BF16 configuration has no extra FP32 master copy. Some intermediate operations retain higher precision.

Muon ratios use recorded BF16 weight norms and an ideal matrix-sign update estimate. The estimate includes the configured update scaling and excludes weight decay. MACRO-fro uses the normalized relation ρₜ = ηₜ.

The Gaussian model uses a fixed reference threshold. It cancels small proposed updates and keeps the others unchanged. It estimates cancellation and retained absolute-update magnitude, not loss values.

Missing samples remain missing. Chart values retain their source records. Section 4.3 and Appendices C.5 and D.3 provide the analysis and experimental details.
